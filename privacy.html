Privacy Policy

JodDesk — last updated 19 November 2026

1. Scope

This policy covers JodDesk, a private, single-user desktop automation tool. The only user is the person who installs and configures it on their own computer.

2. What data is accessed

With the owner's explicit OAuth consent, JodDesk may access the owner's own Google account data limited to the scopes the owner approves: Gmail messages and drafts, Google Calendar events, Google Drive files, Google Docs document content, Google Sheets spreadsheet content, and Google Contacts.

3. How data is used

Data is used only to carry out the tasks the owner requests — for example searching mail, creating calendar events, or reading and writing a document or spreadsheet. JodDesk performs no profiling, advertising, or analytics on this data.

4. Storage and retention

OAuth access and refresh tokens are stored locally on the owner's machine. Message, calendar, and document content is held in memory only while a task runs, unless the owner explicitly saves the output to a file on that same machine. No Google user data is uploaded to any server operated by JodDesk.

5. Sharing

JodDesk does not share, sell, rent, or transfer Google user data to any third party. It does not use Google user data to train or improve generalised machine learning models. Automated processing of the owner's mail or documents may occur only through the model provider the owner has configured, and only scoped to the task requested.

6. Google API Services User Data Policy

JodDesk's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

The owner can revoke JodDesk's access at any time at myaccount.google.com/permissions. Revocation invalidates the stored tokens immediately, and deletion of the local token files removes all credentials held by this tool.

8. Children

JodDesk is not directed to children under 13 and is not offered to the public.

9. Changes

Any change to this policy will be published on this page with a new effective date.

10. Contact

Questions about this policy: use the support address shown on the Google consent screen for this application.
